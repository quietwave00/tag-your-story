## 2026-11-02 사용자 요청 — 상세 정렬과 태그 노트 목록 정보

- 사용자 요청 범위: Track·Artist·Album·Board 상세의 공통 폭과 뒤로가기 정렬, Board 댓글 입력 폭, Track의 태그 노트 목록 기본 배경·태그 배경·본문 미리보기·작성자·날짜·좋아요 수·댓글 수, Board 상세 본문 크기·태그 배경·하트 좋아요.
- 계약 위험: 지정 `migration-server` worktree는 현재 환경에 없었다. 접근 가능한 `tagnote-api`의 `BoardApi` → `BoardController` → `BoardResponse`/`DetailBoardResponse`, `CommentApi` → `CommentController` → `CommentCountResponse` 순서로 정적 확인했다. 목록 DTO에는 두 수치가 없어 현재 페이지 최대 8건에 대해 상세·댓글 수 API를 추가 호출한다. 일부 수치 조회가 실패하면 목록은 유지하고 해당 수치만 표시하지 않는다. 실행 응답 검증은 사용자 확인 대기.
- 사용자 실행 검증: `cd tag-note-react && npm run test && npm run lint && npm run build`. 브라우저에서 상세 4종의 뒤로가기 시작점·폭, 목록 정보와 부분 실패, Board 상세와 댓글 입력 정렬 및 모바일 배치를 확인한다. 검증 결과 전에는 완료 기록으로 이동하지 않는다.
